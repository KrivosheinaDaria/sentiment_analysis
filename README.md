# sentiment_analysis
Сентимент-анализ отзыва/рецензии, классификация на нейтральный/положительный/отрицательный.

Для решения поставленной задачи использовался датасет с Kaggle: https://www.kaggle.com/datasets/mar1mba/russian-sentiment-dataset.
При запуске реализованной программы необходимо скачать файл sentiment_dataset.csv и поместить в папку с main.py.
